# RevivePSVR1 - Thumper v0.1.0

Initial Windows PCVR pre-release package. Download RevivePSVR1-Thumper-v0.1.0-Windows-PCVR.zip.
The player and importer are included; no compilation is required.

Extract the whole ZIP, add your own CUSA03559 base PKG and update 01.06 to
games, start your OpenXR runtime and open Play Thumper VR.bat.
No game, firmware or saves are included.

Rendering scales up to 150% are available for the supported executable.
Earlier headset feedback reported smooth gameplay. Full-game completion and every controller/runtime combination are not verified. 200% rendering is disabled because an earlier test crashed before VR submission.
Back up pc-vr-tests/Thumper/user before upgrading. Review collected logs before sharing.
